What it does

    
orch is a Claude Code session with a few skills and a small TypeScript toolkit. A hook in every session writes one line per event to a local feed; orch reads it and acts within rules you can edit.

    

      
01Watches
Every Claude and Codex session on your machine, who is working, blocked, idle or asking you something.

      
02Queues
Anything that needs you becomes a decision with a recommendation and one phone notification. Your answer gets typed into the right session.

      
03Dispatches
New work goes to a worker in its own git worktree. orch runs your tests when it's done and commits on the branch only if they pass.

      
04Reviews
Claude and Codex review the same change independently. What both find counts; the rest gets checked against the code first.

No commands to learn. These all work as typed.

orch deck

        
Type /deck and a live pane docks next to the chat: every session as a map, a dot running along the line whenever a message moves, each worker's stage, the bus of prompts and replies, open decisions. It's a Claude Code mod, so it lives right in the terminal.

        

          m b w d fmap, bus, workers, decisions, flows
          j kselect a session
          ssteer it with one line
          rread its screen inline
          g crun gates, clean up
          y naccept or reject the decision

Never on its own

    
These always come back to you as a decision. Workers never commit; orch commits on the worker's branch only after your tests pass. The rules are a plain Markdown file you can read and change.

    
pushmergeopen or comment on PRsdeploytouch a databasesend anything outside your machineanswer a permission prompt

  


  

    
Install in a minute

    
No dependencies to install. Setup checks your tools, creates your local files and adds one hook to Claude Code (and Codex). It backs up what it changes.

    

      
Clone and set up
git clone https://github.com/cf-lucas-moskau/orch ~/orch
cd ~/orch && npm run setup

      
Put your name in local.md and your repos with their test commands in projects.md.

      
In a herdr workspace called orch, start it and say hi.
npm start

    

    
Needs macOS, Node 22.6+, Claude Code, herdr and jq. Optional: Codex for two-model work, gh for PRs.
